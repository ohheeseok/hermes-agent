Privacy Policy

Hermes Personal Agent · Last updated: October 27, 2026

1. Who uses this app

Hermes Personal Agent is a personal, self-hosted application used solely by its owner. It is not offered to or used by the general public.

2. Google user data accessed

With the owner's explicit consent through Google OAuth, the app may access:

  • Google Calendar – to read, create and update calendar events
  • Google Drive, Docs and Sheets – to search, read, create and edit files
  • Gmail – to search, read, draft and send email
  • Google Contacts – to look up contact information

3. How the data is used

Google user data is used only to perform tasks that the owner explicitly requests from the assistant. It is not used for advertising, profiling, or any other purpose.

4. Storage and security

  • OAuth tokens are stored locally on the owner's own machine or server.
  • Google user data is not stored on any third-party server operated for this app.
  • Reasonable measures, such as restricted file permissions, are used to protect stored tokens.

5. Sharing

Google user data is not sold, rented, or transferred to third parties. It is not used to develop, improve, or train generalized AI or machine-learning models.

6. Compliance with Google policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Locally stored tokens can be deleted by removing the token file from the server.
